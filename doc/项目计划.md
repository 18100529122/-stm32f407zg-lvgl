# STM32F407 LVGL Demo 项目开发计划

## 1. 项目概述
本项目旨在在正点原子探索者 (Alientek Explorer) STM32F407 开发板上实现一个基于 LVGL (Light and Versatile Graphics Library) 的图形界面演示程序。利用开发板的 FSMC 接口驱动 16 位并行 LCD 和外部 SRAM，结合 FreeRTOS 实时操作系统，展示 LVGL 的流畅交互与丰富组件。

## 2. 硬件资源配置
根据 [README.md](file:///c:/work/github/-stm32f407zg-lvgl/README.md) 的引脚说明，核心硬件配置如下：

### 2.1 显示与触摸
*   **LCD 显示屏**: FSMC 16位并行接口
    *   `LCD_CS`: PG12 (FSMC_NE4)
    *   `LCD_RS`: PF12 (FSMC_A6)
    *   `LCD_WR`: PD5 (FSMC_NWE)
    *   `LCD_RD`: PD4 (FSMC_NOE)
    *   `LCD_BL`: PB15 (背光控制)
    *   `LCD_D0~D15`: PD/PE 端口数据线
*   **触摸屏接口**:
    *   电容屏 (GT9147): I2C 接口
    *   引脚: `CT_SCL` (PB0), `CT_SDA` (PF11), `CT_INT` (PB1), `CT_RST` (PC13)
    *   注意: 触摸引脚与电阻屏 SPI 接口复用，需确保硬件跳线或配置正确。

### 2.2 存储与辅助
*   **外部 SRAM**: 1MB (XM8A51216V33A)，通过 FSMC 接口访问。
    *   主要用于 LVGL 的显存缓冲区和动态内存分配。
    *   **注意**: 为避免 FSMC 总线竞争，ADC 采样缓冲区及 FFT 运算缓存已从外部 SRAM 迁移回 **片内 SRAM**。
    *   `SRAM_CS`: PG10 (FSMC_NE3)
*   **系统状态指示**:
    *   `LED0`: PF9 (系统心跳)
    *   `LED1`: PF10 (状态指示)
*   **调试与通信 (注意引脚复用)**:
    *   `UART1`: PA9/PA10 (115200bps，主要调试接口)
    *   **复用风险说明**: 
        *   `PA2/PA3`: 在以太网 (RMII_MDIO)、RS232 (USART2) 和 PWM_DAC 之间复用，开发时需通过 P4 跳线确认模式。
        *   `PD0/PD1`: CAN1 与 FSMC 地址线/控制线存在复用风险，需确保 FSMC 配置不冲突。

## 3. 软件架构与分层
本项目采用层次化设计，确保代码的高内聚与低耦合，具体分层如下：

*   **App 层 (`Core/app`)**: 存放业务逻辑、数据处理后台任务及自定义接口。
    *   **数据处理模块**: 实现基于 FIFO 的 ADC 数据平滑处理。
*   **Middleware 层 (`Core/Middleware`)**: 
    *   **LVGL**: 图形库核心。
    *   **EasyLogger**: 引入 [EasyLogger](https://github.com/armink/EasyLogger)，实现分级日志打印 (LogDebug, LogInfo, LogWarn, LogError)。
    *   **letter-shell**: 引入 [letter-shell](https://github.com/NevermindZZT/letter-shell)，通过串口实现交互式命令行终端。
    *   **FreeRTOS**: 实时操作系统内核。
*   **BSP 层 (`Core/BSP`)**: 板级支持包，包括 LCD、SRAM、GT9147 触摸屏、ADC (1Msps)、DAC 等底层硬件驱动，并提供高精度延时工具。
*   **驱动层**: STM32Cube HAL 库。

### 第四阶段：接口对接与 App 开发 (已完成)
1.  **[已完成] 接口对接**: 
    *   已实现 `lv_port_disp` (800x480 横屏)。
    *   已实现 `lv_port_indev` (对接 GT9xxx 电容触摸)。
2.  **[已完成] 模拟外设扩展与数据处理**:
    *   **ADC 采样**: 实现 1Msps 高速硬件触发采集 (Timer 2 TRGO)，采用 **固定块 FIFO** 结构确保内存安全。
    *   **启动时序优化**: 将 ADC 启动 (`bsp_adc_start`) 移至数据处理任务内部，确保消费者就绪后再生产数据，消除启动瞬态丢失信号量的问题。
    *   **溢出保护机制**: 实现 `bsp_adc_stop`，在 DMA 回调中检测到 FIFO 溢出时立即停止硬件采集，防止旧数据被覆盖。
    *   **总线竞争优化**: 将 ADC 和 FFT 的所有缓冲区迁移至片内 SRAM，解决与 LCD 任务抢占 FSMC 总线的问题。
    *   **任务解耦**: UI 更新由信号量触发改为 **500ms 定时轮询**，降低了任务间的强耦合。
    *   **自动恢复**: 在 `adc_process` 任务处理完积压数据后自动调用 `bsp_adc_start` 恢复采集。
    *   **DAC 输出**: 建立基础波形输出框架。
3.  **[已完成] 应用展示**: 
    *   [已完成] 基础 UI 框架搭建，包含图表、标签及交互按钮。
    *   [已完成] 事件驱动机制：实现按钮点击数字递增逻辑 (`lv_ui_event.c`)。
    *   [已完成] 控件库扩展：已在 `lv_conf.h` 中启用所有常用控件（Slider, Switch, Roller 等）及布局引擎 (Flex/Grid)。
4.  **[已完成] 稳定性优化**: 
    *   通过调整 NVIC 优先级（ADC=6, LCD=7）及 LVGL 刷新频率（15ms），实现了系统的长期稳定运行。
