# STM32F407 LVGL Demo 项目开发计划

## 1. 项目概述
本项目旨在在正点原子探索者 (Alientek Explorer) STM32F407 开发板上实现一个基于 LVGL (Light and Versatile Graphics Library) 的图形界面演示程序。利用开发板的 FSMC 接口驱动 16 位并行 LCD 和外部 SRAM，结合 FreeRTOS 实时操作系统，展示 LVGL 的流畅交互与丰富组件。

## 2. 硬件资源配置
根据 [README.md](file:///c:/work/github/-stm32f407zg-lvgl/README.md) 的引脚说明，核心硬件配置如下：

### 2.1 显示与触摸
*   **LCD 显示屏**: FSMC 16位并行接口
    *   `LCD_CS`: PG12 (FSMC_NE4)
    *   `LCD_RS`: PF12 (FSMC_A6)
    *   `LCD_WR`: PD5 (FSMC_NWE)
    *   `LCD_RD`: PD4 (FSMC_NOE)
    *   `LCD_BL`: PB15 (背光控制)
    *   `LCD_D0~D15`: PD/PE 端口数据线
*   **触摸屏接口**:
    *   电容屏 (GT9147): I2C 接口
    *   引脚: `CT_SCL` (PB0), `CT_SDA` (PF11), `CT_INT` (PB1), `CT_RST` (PC13)
    *   注意: 触摸引脚与电阻屏 SPI 接口复用，需确保硬件跳线或配置正确。

### 2.2 存储与辅助
*   **外部 SRAM**: 1MB (XM8A51216V33A)，通过 FSMC 接口访问，用于 LVGL 的显存缓冲区和动态内存分配。
    *   `SRAM_CS`: PG10 (FSMC_NE3)
*   **系统状态指示**:
    *   `LED0`: PF9 (系统心跳)
    *   `LED1`: PF10 (状态指示)
*   **调试与通信 (注意引脚复用)**:
    *   `UART1`: PA9/PA10 (115200bps，主要调试接口)
    *   **复用风险说明**: 
        *   `PA2/PA3`: 在以太网 (RMII_MDIO)、RS232 (USART2) 和 PWM_DAC 之间复用，开发时需通过 P4 跳线确认模式。
        *   `PD0/PD1`: CAN1 与 FSMC 地址线/控制线存在复用风险，需确保 FSMC 配置不冲突。

## 3. 软件架构与分层
本项目采用层次化设计，确保代码的高内聚与低耦合，具体分层如下：

*   **App 层 (`Core/App`)**: 存放业务逻辑、LVGL 界面代码及自定义 Shell 命令。
*   **Middleware 层 (`Core/Middleware`)**: 
    *   **LVGL**: 图形库核心。
    *   **EasyLogger**: 引入 [EasyLogger](https://github.com/armink/EasyLogger)，实现分级日志打印 (LogDebug, LogInfo, LogWarn, LogError)。
    *   **letter-shell**: 引入 [letter-shell](https://github.com/NevermindZZT/letter-shell)，通过串口实现交互式命令行终端。
    *   **FreeRTOS**: 实时操作系统内核。
*   **BSP 层 (`Core/BSP`)**: 板级支持包，包括 LCD、SRAM、GT9147 触摸屏等底层硬件驱动，并提供高精度延时工具。
*   **驱动层**: STM32Cube HAL 库。
